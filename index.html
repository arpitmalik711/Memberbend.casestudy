03 Assumptions vs Reality

What Was Designed vs What Happened

Mount placed mid-span — correct for kinematics, wrong for load path. Bending dominates; axial capacity of the tube is irrelevant.

☑ Assumed: Load Path
Mount placed 241 mm (9.5 in) away from Node 1 for correct damper angle and stroke geometry.
Assumed: Member carries load axially — efficient use of tubular section.
✕ Reality: Load Path
Mid-span transverse load creates bending moment M = F·a(L−a)/L. Axial strength of tube is irrelevant — bending dominates entirely.
☑ Assumed: Stress Level
Initial design check estimated stresses within safe envelope.
Assumed FOS ≥ 2.0 per Baja SAE structural guidelines.
✕ Reality: Stress Level
Bending + Axial load + Twisting drives σVM to 1136 MPa.
Actual FOS = 0.67 — structural failure was mathematically certain.
☑ Assumed: Material Margin
Sult = 855 MPa assumed sufficient for the design load envelope with standard safety factor applied.
✕ Reality: Material Margin
Calculated stress exceeds Sult by 32.9%. Material substitution alone cannot fix a load-path geometry error of this magnitude.
▶ Key Insight
This was not a material failure. It was a geometry of load path failure. The correct fix is therefore geometric: redirect loads through triangulation — not material upgrade.

05 Root Cause Analysis

Why the Failure Occurred

Mid-span mount → simultaneous bending + axial + twisting. Combined σVM = 1136 MPa. FOS = 0.67. Failure certain.

◈ Analytical Method — Euler–Bernoulli Beam Theory + Torsion
(1) Decompose damper axis force into transverse & axial components at mount node under 4g.
(2) Free-body diagram of chassis member.
(3) Bending moment: M = F·a(L−a)/L (peak at mount, a = 241 mm (9.5 in) from Node 1).
(4) Bending stress: σb = M·c/I (extreme fibre); τtwist = T·c/J from torsion; σaxial = F∥/Apipe.
(5) Von Mises: σVM = √(σ² + 3τ²) where σ = σaxial + σb and τ = τtwist → 1136 MPa.
(6) FOS = Syield/σVM = 763/1136 = 0.67 — structural failure was mathematically certain.

08b Analytical vs FEA — Stress Discrepancy

Why Calculated Stress is Higher than FEA Result

Hand calc uses conservative assumptions → gives upper bound. FEA models real 3D behaviour → lower but more accurate. Both flag the same failure zone.

#Assumption (Hand Calculation)Reality (FEA / Real Frame)
1 Member was assumed to be an isolated individual beam Load is distributed to multiple tubes in the real frame — neighbouring members share the load
2 Member was assumed as simply supported at both ends Joints have some stiffness — not fully fixed, but not purely simply supported either
3 Load applied at a single point → point load → higher stress Load is distributed through the bracket to an area of tube — not a true point load
4 Assumed all 3 stresses acting at the same cross-section simultaneously Bending is higher at the point of load application; axial is higher elsewhere; torsional stress similarly distributed — FEA combines stresses at nodes accurately
▶ Engineering Interpretation
Hand calc: conservative upper bound (FOS 0.67). FEA: realistic distribution (FOS 0.92). Both confirm failure. Discrepancy is expected — not a contradiction.

09 Engineering Decision

Triangulated Load Path Redirection

Root cause is geometric — fix must be geometric. Added triangulating member from mount node to adjacent frame node.

✕ Rejected: Upsize Member
Reduces stress but bending remains. Adds weight. Doesn't fix load path.
✓ Chosen: Triangulation
Load routes through node → pure axial in all members. M ≈ 0. Minimal weight penalty.
◈ Why Triangulation Eliminates Bending
At a true truss node, load resolves into axial components only — no moment arm, no bending. Eccentricity e → 0; M = F·e → 0.
